# Second adult worker asset

This presentation asset derives from Microsoft's [Male_Adult_05](https://github.com/microsoft/Microsoft-Rocketbox/tree/0943055db6ec570bcef9f2c8b41c9e5467c808f9/Assets/Avatars/Adults/Male_Adult_05) in the Rocketbox collection. The model and source textures use the included [MIT license](LICENSE.md). [source.json](source.json) pins the original files and prepared output.

The vest, long sleeves, trousers, work shoes, mature face and short hair give the second actor a silhouette distinct from the existing jacketed worker. This is a candidate field worker, not a claim that the character reaches the requested human appearance quality. The original head, body and hair textures remain together on their source mesh; the visible differences do not depend on a swapped face or procedural skin.

The original model has one skinned mesh, three material surfaces, 80 skin bindings and 81 named bones. Its bone names and parent order match the first adult, but its rest pose and body proportions differ. The separate male walking and running takes are prepared as named-bone resources rather than applying the first adult's absolute leg poses. The presenter selects this asset for actor Q and keeps a separate first-person hand mesh for each source. The mesh and textures have no collider, controller, input, inventory or saved state.

The runtime mesh and five maps were converted from the pinned editable FBX and TGA files using Godot 4.7.2. The maps use the same 1,024-pixel color and 512-pixel normal/opacity preparation as the first adult. Normal vectors were renormalized and saved losslessly; the retained preparation report records the measured length error. The original specular maps are source references, not roughness data. A passive Godot render checked front, side and back appearance before integration. Source compatibility and fixture pixels do not establish natural motion, full-scene performance, human preference or the quality of the complete game.
