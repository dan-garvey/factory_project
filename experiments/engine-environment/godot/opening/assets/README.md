## Preparation and inspection

Use [mechanical preparation](../../../../../native/asset-preparation/README.md)
and [foliage preparation](../../../../../native/foliage-assets/README.md) for
reproducible source conversion. Worker folders retain their rig/source notes.
Import the complete captured project before inspecting resources; keep output
in an owned external directory under ordinary resource admission.

For passive buildable-resource views, the existing `machine_detail_check.gd`
mode `--render-buildable-resources` requires
`FACTORY_RESOURCE_RENDER_MODE=isolated` and an existing absolute
`FACTORY_RESOURCE_RENDER_OUTPUT` directory. Use a private virtual display and
a bounded supervisor. Headless dummy rendering cannot produce those images.
The fixture refuses existing results and retains failed captures.

Inspect normal-camera shape, material scale, connections and clearances as well
as studio close-ups. Art follows native component identities, dimensions,
phase and occupancy; it cannot create foundations, machine parts or stock.
Passive resource views establish appearance only, not ordinary gameplay,
physical correctness, performance or human preference. Dated studies and
rejected alternatives are recorded in the owning art Beads.
